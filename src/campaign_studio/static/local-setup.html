Local API key setup

Saved images, local editing, and export work without an API key. New image generation uses your OpenAI account.

Using the app

When Production needs a key, choose Add your OpenAI API key. The masked entry saves to the .env file in the directory where this installation was launched, and activates it without a restart. Saving a key does not verify access or start an image request. Return to Production for a separate deliberate action.

Manual setup

For either documented installation route, open a terminal in the directory used to start Motif. Add or update OPENAI_API_KEY in that directory’s private .env file, then restart the app from the same directory. Keep unrelated .env entries intact. Do not put a key in campaign briefs or exports.

An OPENAI_API_KEY variable explicitly supplied in the launch environment takes precedence, including an empty value. In that case, update that environment variable and relaunch; the app will not save a lower-priority replacement.

If saving is not confirmed

Check the local .env file and its permissions without sharing its contents. A configured key alone does not prove that a particular submission succeeded. Do not repeat a submission automatically. The key is private local configuration and is excluded from the application source and campaign packages.
