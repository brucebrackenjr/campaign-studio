Local API key setup

Saved images, local editing, and export work without an API key. New image generation uses your OpenAI account.

Using the app

When Production needs a key, choose Add your OpenAI API key. On macOS and Linux the masked entry saves to the installation’s private .env. On Windows it saves an encrypted key for your Windows account inside Workspace/private. A successful save activates the key. Saving a key does not verify access or start an image request. Return to Production for a separate deliberate action.

Manual setup

Set OPENAI_API_KEY in the environment before launching Motif. On macOS and Linux, you may also use the private .env in the extracted Motif folder. Restart the app after manual changes. Do not put a key in campaign briefs or exports.

An OPENAI_API_KEY variable explicitly supplied in the launch environment takes precedence, including an empty value. In that case, update that environment variable and relaunch; the app will not save a lower-priority replacement.

If saving is not confirmed

Check your account and the local folder permissions. A configured key alone does not prove that a particular submission succeeded. Do not repeat a submission automatically. The key is private local configuration and is excluded from the application source and campaign packages.
