This fictional HOLD campaign uses two distinct source roles:

- `saved-concept.png` is the genuine brush-roll master returned by one application image request on October 29, 2026. The brief records its exact SHA-256, model, and generation date. The concept had no product photograph before that original request.
- `product-b-scene.png` is the supplied chalk scene, created with AI assistance during input preparation. The application reuses it locally.
- `logo.png` is the locally authored fictional HOLD wordmark, set using licensed Noto Sans.

Replay copies these exact saved assets into a new local workspace, composes 12 PNGs, and makes zero provider requests. No attempt history is fabricated. Raw responses, original private prompt records, account information, and credentials are not included.

No prohibited words are configured initially. The CLI self-check changes the Spanish headline to “Para cada movimiento.” across both products, preserving CTA and the six English images. Configured prohibited rules are tested separately; every match blocks. Both languages use supplied copy, with no automatic translation.

The brush roll is an invented concept, not evidence of product-photograph preservation. The chalk image is enlarged for vertical and landscape formats, so fine details are softer than in its native source. Automated checks and technical demonstration review do not approve publication; the recipient still reviews the imagery, wording, and intended use.
